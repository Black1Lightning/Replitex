# Replitex ⚡

## 🌐 Русский

**Replitex** — это удобный десктопный инструмент для массового поиска и замены текста в именах файлов, папок, а также внутри содержимого текстовых документов. 

Приложение оснащено гибкой системой фильтрации, безопасным режимом предпросмотра и поддержкой различных тем оформления.

### ✨ Основные возможности

* 🔍 **Поиск и замена:** Работает как с названиями файлов и папок, так и с их текстовым содержимым.
* 🛡️ **Гибкая система игнорирования:**
  * Игнорирование по ключевым словам (в путях или содержимом).
  * Исключение конкретных файлов или папок.
  * Исключение файлов по расширению (например, `.png`, `.bin`, `.jpg`).
  * Автоматический пропуск бинарных и медиафайлов.
* 🎯 **Точные опции поиска:**
  * Учет регистра (`Case Sensitive`).
  * Поиск только целых слов (`Whole Words Only`).
  * Рекурсивная обработка подпапок.
* 👁️ **Безопасный предпросмотр:** Просмотр итогового дерева изменений до физической модификации файлов.
* 🎨 **Интерфейс и кастомизация:**
  * Многоязычность (Русский / English).
  * 4 встроенные темы оформления: *Светлая*, *Тёмная*, *Ядовитый пурпур*, *Полночное золото*.
  * Детальный журнал (лог) всех совершенных операций.

### ⚙️ Режимы работы

1. **Замена (Replace):** Модифицирует существующие файлы и папки прямым переименованием и заменой текста внутри.
2. **Копирование 1 (Copy 1):** Скопирует и обработает только объекты в корне выбранной папки, к которым применима замена.
3. **Копирование 2 (Copy 2):** Создает дубликаты структуры директорий и файлов с примененной заменой, сохраняя оригиналы нетронутыми.

## 🌐 English

**Replitex** is a handy desktop utility for batch searching and replacing text across file names, folder names, and file contents. 

Equipped with a powerful filtering system, a safe preview mode, and customizable visual themes, it simplifies bulk text operations with precision and safety.

### ✨ Features

* 🔍 **Search & Replace:** Target file/folder names and in-file text simultaneously.
* 🛡️ **Advanced Ignore Rules:**
  * Ignore items by specific keywords (in path or content).
  * Exclude specific files or entire directories.
  * Filter out specific file extensions (e.g., `.png`, `.bin`, `.jpg`).
  * Built-in safety against modifying binary/media files.
* 🎯 **Precision Search Options:**
  * Case sensitive search.
  * Match whole words only.
  * Optional recursive subfolder processing.
* 👁️ **Safe Preview Mode:** Inspect proposed changes in an interactive tree view before applying them to disk.
* 🎨 **UI & Customization:**
  * Bilingual interface (English / Russian).
  * 4 color themes: *Light*, *Dark*, *Poisonous Purple*, and *Midnight Gold*.
  * Real-time operation logs with clear event tracking.

### ⚙️ Processing Modes

1. **Replace:** Modifies existing files and directories directly in place.
2. **Copy 1:** Copies and applies replacements only to top-level items matching search criteria.
3. **Copy 2:** Replicates the directory structure and applies replacements to duplicates while leaving original files untouched.
